# HTML Foundations

This folder contains my HTML learning journey, covering the core building blocks
used to create structured web pages.

The focus of this section is understanding how HTML documents are structured,
how different elements work together, and how to create meaningful and accessible
web page content.

## 🎯 Purpose

The goal of this section is to build a strong foundation in HTML before moving
into CSS, JavaScript, and full-stack web development.

The concepts learned here are applied through small practical exercises rather
than only theoretical examples.

## 🧠 Concepts Covered

- HTML document structure
- `<!DOCTYPE html>`
- `<html>`, `<head>`, and `<body>`
- Headings
- Paragraphs
- Text formatting
- Lists
- Links
- Images
- Audio
- Video
- Tables
- Forms
- Form controls
- Labels
- Input elements
- Buttons
- Semantic HTML basics
- Attributes
- IDs and classes
- Connecting HTML with CSS
- Connecting HTML with JavaScript
