# 📚 Book Heaven

Book Heaven is a multi-page bookstore website designed to showcase books across different genres through an organized and welcoming browsing experience.

The project focuses on building a structured frontend website using HTML and CSS, with dedicated pages for book collections, genre categories, and additional information.

## 🎯 Project Objectives

* Build a multi-page bookstore website.
* Organize books into different genres.
* Create a consistent and user-friendly browsing experience.
* Practice HTML structure, CSS styling, and asset organization.
